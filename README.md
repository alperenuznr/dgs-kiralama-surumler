# DGS Kiralama — sürümler

Bu depo yalnızca **DGS Kiralama** programının kurulum dosyalarını ve otomatik güncellemelerini barındırır. Kaynak kod burada değildir.

- Son sürüm: [Releases](https://github.com/alperenuznr/dgs-kiralama-surumler/releases/latest)
- Windows: `DGS Kiralama_x.y.z_x64-setup.exe`
- macOS: `DGS Kiralama_x.y.z_universal.dmg`

Kurulu program yeni sürümleri buradan kendisi bulur (Ayarlar › Güncellemeler).
